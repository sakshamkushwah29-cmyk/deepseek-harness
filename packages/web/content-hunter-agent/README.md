> Featuring the **Indian Wedding Creator Strategy**, 5-Hook Engine, and Middle Layer Trust Funnel.

## 🌟 Live Features

1. **Idea Radar**: Target audience filtering (Couples, Founders, Other Creators, People Like Me).
2. **5-Hook Engine**: Generates 5 distinct psychological hook angles for any topic:
   - Behind-The-Lens (BTL)
   - Counter-Intuitive (CI)
   - Observational (OBS)
   - Client Defense (CD)
   - Micro-Story (MS)
3. **Stage Cues Built-in**: Directs filmmakers with `[One Long Hold]` and `[How I Wait]` quiet observational pacing.
4. **Middle Layer Trust Funnels**: 5-Day weekly content cadence designed to educate and build authority without hard-selling (*"Because I don't sell — I just educate, spread knowledge, information, and fun"*).
5. **Interactive Skill Graph**: Full access to the content strategy graph and audience archetypes.

## 🚀 Deploy to Vercel

### Option 1: 1-Click Deploy
Click the button below to deploy your own instance to Vercel:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fsakshamkushwah29-cmyk%2Fcontent-hunter-agent)

### Option 2: Import via Vercel Dashboard
1. Go to [vercel.com/new](https://vercel.com/new).
2. Select **`sakshamkushwah29-cmyk/content-hunter-agent`**.
3. Click **Deploy**.

*(Optional)* Configure Environment Variables:
- `DEEPSEEK_API_KEY` (or your OpenRouter key)
- `DEEPSEEK_MODEL` (e.g. `deepseek-chat` or `minimax/minimax-m3:free`)
