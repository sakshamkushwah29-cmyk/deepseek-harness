# Engine: Repurposing Workflow (1 Shoot -> 3 Deliverables)

## The Core Concept
To sustain **5 posts per week** without creator burnout, every high-effort concept is cross-formatted:

```
[Master Video Concept / Behind-The-Scenes Experience]
           │
           ├── 1. Talking Head Reel (Direct to camera, unhurried, personal voice)
           │
           ├── 2. 5-Slide Carousel (Detailed technical / educational breakdown)
           │
           └── 3. POV Value Overlay (Atmospheric 7s b-roll loop + in-depth caption)
```

---

## Repurpose Conversion Rules
1. **Talking Head Script -> Carousel**:
   - Extract the 3 main arguments from the speech -> Slides 2, 3, 4.
   - Convert spoken hook into high-impact slide 1 typography.
   - Add summary checklist to Slide 5.

2. **Talking Head Script -> POV Overlay**:
   - Take the most poignant sentence (the "quote of the script") -> Overlay text.
   - Place the full context, technical explanation, and recommendations in the caption.
   - Pair with an unreleased 7-second b-roll clip from the shoot.

3. **Carousel -> Talking Head**:
   - Take the carousel's slide 3 & 4 insights and speak them conversationally with hands-on gear demonstration.
